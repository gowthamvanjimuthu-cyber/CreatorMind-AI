About The Platform

Enterprise-grade architecture tailored for creative professionals.

Preserve & Scale Your Unique Voice

CreatorMind AI is a state-of-the-art content generation platform built upon an IBM Granite-compatible architecture. It utilizes an advanced Retrieval-Augmented Generation (RAG) pipeline to ingest, analyze, and learn from your past content.

Built with a robust full-stack foundation utilizing React, FastAPI, Supabase, and ChromaDB, the platform offers absolute data isolation and high-performance streaming AI responses.

System Architecture

Designed for scale, security, and context-aware intelligence.

Frontend Layer

React + Vite application using TailwindCSS and Zustand for state management. Ensures rapid client-side routing, localized UI states, and handles streaming SSE data elegantly.

Backend Engine

Asynchronous FastAPI Python server orchestrating SQLite for relational data mapping, background task queues, and strict API validation schemas via Pydantic.

RAG Intelligence

Docling parses complex documents which are chunked and embedded before storage in ChromaDB vector space. Context is injected into IBM Granite models for generation.
