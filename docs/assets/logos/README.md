# Logos Folder

Place all brand identity assets here.

## Expected Files

| Filename | Description |
|----------|-------------|
| `logo_light.svg` | Full logo for light backgrounds |
| `logo_dark.svg` | Full logo for dark backgrounds |
| `logo_icon_only.svg` | Icon-only version (no text) |
| `favicon.ico` | Browser tab favicon (32x32) |
| `logo_light.png` | For READMEs that don't render SVG |
| `logo_dark.png` | Same as above, dark variant |

## Recommended Design
- Primary brand color: **Indigo `#4f46e5`**
- Background: **Dark `#0f172a`**
- Use a brain or sparkle motif representing the Creator Intelligence Engine
