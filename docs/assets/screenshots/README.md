Store all static UI captures here. Used directly inside `README.md` and documentation.

## Naming Convention

`view_[feature]_[theme].png`

## Technical Requirements
- Resolution: **1920×1080** (or 2x Retina: 3840×2160)
- Format: **PNG** (use JPEG only for large hero banners)
- Browser: Use incognito mode with no browser extensions visible
- Tool: Use [Responsively.app](https://responsively.app/) for mobile captures
