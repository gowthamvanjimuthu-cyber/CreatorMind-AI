# Demo Assets Folder

Store all large-format promotional assets here — social previews, banners, and demo video link references.

## Expected Files

| Filename | Dimensions | Purpose |
|----------|-----------|---------|
| `promo_github_banner.png` | 1920×600 | README hero banner (top of README.md) |
| `promo_social_preview.png` | 1280×640 | GitHub OpenGraph card (Settings → Social Preview) |
| `promo_demo_cover.jpg` | 1280×720 | YouTube/video thumbnail |

## Demo Video
Create a `DEMO_LINKS.md` inside this folder and place actual video URLs there:
```markdown
# Demo Video Links
- Full Demo (YouTube): [Link TBD]
- Short Demo (Twitter/X): [Link TBD]
- IBM Builders Submission Video: [Link TBD]
```

## Banner Design Spec
- **Background:** `#0f172a` (slate-900)
- **Accent:** `#4f46e5` (indigo-600) glowing radial gradient
- **Typography:** Inter Bold, white text
- **Tagline:** *"AI That Writes In Your Voice. Powered by IBM Granite."*
- **Elements:** Float the Dashboard screenshot at 30% opacity as background texture
