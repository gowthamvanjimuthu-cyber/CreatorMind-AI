# GIFs Folder

Store all animated demo GIFs here. These are the most powerful README engagement tools — they prove the app works without a user needing to clone it.

## Naming Convention

`demo_[action]_[speed].gif`  
*(speed: `fast` = 2x, `normal` = 1x)*

## Required GIFs

| Filename | Action to Record | Max Duration | Max Size |
|----------|-----------------|--------------|----------|
| `demo_upload_workflow_fast.gif` | Drag PDF → Parsing bar → "Indexed" badge | 10s | 5MB |
| `demo_chat_rag_normal.gif` | Type query → "Thinking…" → SSE stream | 12s | 5MB |
| `demo_streaming_fast.gif` | Close-up of token typewriter effect | 6s | 3MB |
| `demo_writing_studio_normal.gif` | Select type → Generate → Output | 15s | 6MB |
| `demo_workspace_switch_fast.gif` | Switch workspace → data isolation clear | 8s | 3MB |
| `demo_dashboard_normal.gif` | Scroll dashboard panels + live metrics | 8s | 4MB |

## Recording Tools
| OS | Recommended Tool |
|----|-----------------|
| Windows | [ScreenToGif](https://www.screentogif.com/) (free) |
| macOS | [CleanShot X](https://cleanshot.com/) |
| Linux | [Peek](https://github.com/phw/peek) |

## Optimization
After recording, optimize every GIF using [Gifski](https://gif.ski/) or [Ezgif.com](https://ezgif.com/optimize) to reduce file size without losing quality.
