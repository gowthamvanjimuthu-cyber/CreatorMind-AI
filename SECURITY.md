# Security Policy

## Supported Versions

Currently, only the main branch (`v1.x`) of CreatorMind AI is fully supported with active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a primary concern given that CreatorMind RAG ingests potentially sensitive user documents into ChromaDB spaces.

**Do NOT report security vulnerabilities via public GitHub Issues.**

If you discover a security vulnerability (such as multi-tenant workspace leakage or JWT bypasses), please send an email directly to the core maintainer team (or the repository owner). 

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. Once the vulnerability is patched, we will request your permission to credit you in our Security Advisories.

## Safe Harbor
We strongly support security researchers and promise not to take legal action against you provided you act in good faith and allow us time to patch vulnerabilities prior to public disclosure.
